# RiskGuard AI — 60-Second Elevator Pitch

RiskGuard AI is an explainable fraud-risk investigation prototype. It addresses a practical gap in fraud review: an ML probability can flag a transaction, but it does not explain the evidence an analyst needs. The system uses a saved XGBoost baseline on real Kaggle transaction fields, adds transparent synthetic behavioral signals, and passes both into a deterministic risk engine that owns the authoritative score and risk level. An evidence-based Investigator then summarizes the result. An optional AI provider can improve the explanation, but it is guarded, advisory, and unable to change the probability, behavioral points, score, level, or rules. If AI is unavailable or unsafe, the deterministic fallback still works. FastAPI, SQLite audit events, authentication, validation, rate limiting, and a read-only Streamlit console make the flow demonstrable and traceable. The held-out baseline reports precision 0.914634, recall 0.789474, F1 0.847458, and PR-AUC 0.821925 on 56,746 rows. Those are prototype evaluation results—not production claims—and the behavioral data is synthetic.
